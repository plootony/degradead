# Оружие IK — редактор хвата DGD

Плагин включён в проекте. Откройте верхнюю вкладку **Оружие IK** рядом с 3D / Script
или меню **Project → Tools → Оружие IK DGD**. Перезапустите редактор после установки,
если вкладка ещё не появилась.

## Настройка

1. Выберите AKS-74, создайте копию профиля или нажмите **Добавить модель…**
   (FBX, GLB/GLTF, TSCN). Каждый профиль получает отдельный идентификатор.
2. Выберите позу: стоя / присед / лёжа, с прицеливанием или без него.
   Список анимаций позволяет проверить хват в движении. Есть пауза, скорость и
   шкала времени. Поза выбирает поправку оружия, а список анимаций — базовый клип.
3. **Оружие — базовая опора** задаёт общий монтаж относительно исходной правой
   кисти. **Оружие — поправка позы** задаёт дополнительное положение и вращение
   для выбранной позы. Настройте базу, затем поправки поз.
4. **Правая / левая кисть** задают положение запястья и его ориентацию относительно
   оружия. **Локти** задают направление сгиба: это смещение от локтя исходной
   анимации в системе координат скелета. **Дуло** задаёт начало трассера.
5. Тяните цветные маркеры ЛКМ в плоскости экрана. ПКМ вращает вид, колесо меняет
   масштаб. Для точных значений и вращения используйте поля XYZ. При перетаскивании
   анимация временно замирает. Жёлтым выделена выбранная точка.
6. У каждой позы независимая сила IK каждой руки (0–1). Общая скорость перехода
   управляет плавностью включения и смены поз. Длина модели нормализуется в метрах;
   после изменения размера проверьте точки хвата и дуло.
7. **Использовать в игре** выбирает стартовый профиль для новых игроков.
   **Сохранить** записывает `library.tres`; затем перезапустите игру. Работают
   Ctrl+Z / Ctrl+Shift+Z, сохранение при запуске игры и отключении плагина.

В инспекторе профиля доступны названия костей, положение оружия за спиной,
список скрываемых корневых узлов модели и все параметры поз. Идентификатор оружия
должен быть уникальным и одинаковым во всех сборках. Новым моделям нужно вручную
настроить ориентацию, обе кисти и дуло; стартовые значения рассчитаны на AKS-74.

## Работа в игре

Один и тот же модификатор работает в предпросмотре и на игроках. Сначала применяется
базовая анимация Mixamo, затем модификаторы корпуса и ног, затем оружие и IK рук.
Оружие использует исходную анимированную кисть как опору; решённая IK кисть не
возвращается в расчёт опоры, поэтому поза не уплывает при повторных кадрах.

IK изменяет только вращение костей, не растягивая руки. Недостижимая точка
ограничивается длиной руки; расстояние до цели показывается под предпросмотром.
При перезарядке, смене оружия, ближней атаке и смерти влияние IK плавно уходит.
Пальцы сохраняют базовую анимацию: отдельные позы пальцев и взаимодействие с
магазином этот плагин не создаёт. Точный художественный хват требует настройки.

`Player.server_set_weapon_profile(id)` позволяет хосту менять профиль во время
игры. По сети передаётся идентификатор; модели и настройки должны присутствовать
у всех клиентов. Это система поз; стрельба настраивается в отдельной вкладке «Стрельба». Сейчас в каталоге одна имеющаяся модель — AKS-74.

Хитбоксы и привязка крови используют итоговые позы после IK. Мышь и камера не
ожидают решения IK или сетевого подтверждения.

## Проверки

```sh
python3 tests/run_weapon.py /absolute/path/to/godot
python3 tests/run_network.py /absolute/path/to/godot
```

Первый запуск проверяет IK, редактор (временно меняет и восстанавливает профиль),
два клиента Photon и боевые эффекты. Второй — основную сетевую регрессию.
Для снимка редактора:

```sh
godot --path . --editor --rendering-method gl_compatibility -- --weapon-plugin-test --preview-only
```

Результат: `/tmp/dgd-weapon-editor.png`. Запускайте проверки редактора без
параллельного ручного изменения каталога, поскольку они проверяют запись на диск.

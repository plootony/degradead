# DGD Camera — настройки камеры

Плагин редактора для Godot 4.7. В проекте уже включён.

## Как открыть

Откройте вкладку **Камера** справа рядом с инспектором. Если вкладка скрыта,
выберите **Project → Tools → Камера DGD** или **Editor → Editor Docks → Камера**.
При необходимости включите **DGD Camera** в **Project → Project Settings → Plugins**.

1. Выберите профиль: первое лицо, первое лицо с прицеливанием, третье лицо,
   третье лицо с прицеливанием.
2. Измените значения. Предпросмотр реагирует сразу. В нём можно включить шаги,
   проверить выстрел/попадание и выбрать стоячую, сидячую или лежачую позу.
3. Нажмите **Сохранить** и запустите игру. Изменения также сохраняются перед
   запуском из редактора, при сохранении проекта и выключении плагина.
   Уже запущенный отдельный процесс игры нужно перезапустить.

**Ctrl+Z / Ctrl+Shift+Z** отменяют и возвращают изменения. **Сбросить профиль**
возвращает исходные значения только выбранного режима; сброс тоже отменяется.

## Параметры каждого профиля

| Параметр | Значение |
| --- | --- |
| Дальность | Расстояние камеры назад от опорной точки, 0–3 м. |
| Высота стоя | Высота от земли в стоячей позе; приседание и положение лёжа учитываются автоматически. |
| Смещение вбок | Положительное — вправо, отрицательное — влево. |
| Смещение назад | Дополнительный сдвиг; отрицательное значение выдвигает камеру вперёд. |
| Наклон вверх | Дополнительный вертикальный угол, положительный — вверх. |
| Угол обзора | FOV камеры. |
| Скорость перехода | Больше — быстрее сменяются положения и FOV. Мышиный ввод не сглаживается. |
| Шаги: сила / частота | Угловое покачивание при движении по земле; частота указана для обычного бега. |
| Выстрел: сила / затухание | Угловой импульс камеры при собственном выстреле. |
| Попадание: сила / затухание | Угловой импульс при подтверждённом уменьшении здоровья. |

Сила **0** отключает соответствующий эффект. Углы задаются в градусах,
расстояния — в метрах, затухание — в секундах. Предпросмотр содержит условный
манекен и общую с игрой логику камеры; это не предпросмотр анимаций персонажа.

## Подключение к игре

Профили лежат в `camera_settings.tres`. `Player.camera_settings` ссылается на
этот ресурс. `rig.gd` отвечает за расстояние, FOV, опорную высоту, наклон и
переходы; `motion.gd` — за покачивание и затухающие импульсы. Preview использует
эти же компоненты. В игровом режиме `SpringArm3D` сокращает дистанцию у стен.
При экстремальном наклоне и низкой/высокой опорной точке длина плеча
автоматически ограничивается допустимым радиусом камеры для сетевых выстрелов.

Положение первого лица опирается на высоту стойки, а не на колебания кости
головы: силу покачивания теперь можно действительно настроить или отключить.
Мышиные углы, скорость персонажа и сетевой протокол не изменяются тряской.
Луч выстрела соответствует направлению отображаемой камеры в момент нажатия;
импульс от этого выстрела начинается после захвата луча. Последующие выстрелы
учитывают текущее направление камеры, включая ещё не затухшую тряску.
Сетевые откаты не запускают эффекты выстрела повторно. Новая жизнь сбрасывает
импульсы. Чужие камеры не получают локальные эффекты.

## Проверки

```sh
godot --headless --path . --script res://tests/camera_runtime.gd
godot --path . --rendering-method gl_compatibility --script res://tests/camera_runtime.gd -- --visual
godot --editor --path . --rendering-method gl_compatibility -- --camera-plugin-test --visual
python3 tests/run_network.py /absolute/path/to/godot
```

Проверка редактора временно меняет и восстанавливает профиль; запускайте её
в тестовой копии проекта. Скриншоты сохраняются в `/tmp/dgd-camera-view-0.png`
… `3.png` и `/tmp/dgd-camera-editor.png`.

Для полного сетевого пути выстрел → урон → тряска запустите два процесса:

```sh
godot --headless --path . --script res://tests/camera_peer.gd -- --autojoin --room=UNIQUE_CAMERA_ROOM
```

API редактора: [EditorDock](https://docs.godotengine.org/en/stable/classes/class_editordock.html),
[EditorUndoRedoManager](https://docs.godotengine.org/en/stable/classes/class_editorundoredomanager.html).
